## Запуск на Windows в VS Code

1. Полностью распакуй ZIP, например в `C:\Projects\OKEI-PECHAT`. Не запускай файлы прямо из ZIP.
2. Открой VS Code → File → Open Folder и выбери папку `OKEI-PECHAT`, внутри которой лежит `package.json`.
3. В Terminal → New Terminal выполни `node --version`. Нужен Node.js 18 или новее; для новой установки выбирай поддерживаемую LTS-версию Node.js. После установки перезапусти VS Code.
4. Выполни:

```powershell
node scripts/serve-local.cjs
```

5. Открой в браузере **http://127.0.0.1:8080/**. Используй этот адрес и порт постоянно, чтобы видеть одни и те же локальные данные.
6. Для остановки нажми `Ctrl+C` в терминале.

Альтернативы: двойной щелчок по `start-windows.cmd`; команда `npm start`; или Terminal → Run Task → «ОКЭИ ПЕЧАТЬ: запустить локально». Команда с `node` подходит и когда PowerShell блокирует `npm.ps1` — менять политику PowerShell не требуется. `npm install`, Git, плагины Sites и расширения VS Code для запуска не нужны. Проверять ZIP можно и без входа в ChatGPT.

Если порт занят, закрой другой экземпляр сервера. Для другого порта в PowerShell: `$env:PORT=8081`, затем `node scripts/serve-local.cjs` и адрес `http://127.0.0.1:8081/` (у другого порта будет отдельное хранилище браузера).

**Не открывай `dist/index.html` двойным щелчком через `file://`.** В проекте используются пути от корня сайта, ES-модуль PDF.js, Web Worker и браузерные API. Нужен HTTP-сервер с корнем `dist`. `localhost` / `127.0.0.1` также дают контекст для Web Crypto.

## Демо-вход

| Роль | Логин | Пароль |
|---|---|---|
| Заказчик | `student_23` | `okei2026` |
| Сотрудник | `staff_01` | `okei2026` |

Роль определяется существующим кодом входа. Регистрация демонстрационная: новый аккаунт живёт только в текущей вкладке до перезагрузки. Это сохранённое поведение оригинала, не новая серверная авторизация.

## Фактический стек

- HTML5, CSS3 и обычный JavaScript; без React, Vue, TypeScript и сборщика.
- CSS-анимации, Web Animations API, View Transitions API с fallback, адаптивные CSS media queries.
- Canvas 2D для конструктора мерча, SVG и растровые изображения. Скульптура PDF создаётся HTML/CSS, без Three.js.
- Локальная PDF.js 5.7.284 и её Worker: `dist/assets/pdf.mjs`, `dist/assets/pdf.worker.mjs`. Библиотека уже включена; лицензии в её заголовках сохранены.
- `localStorage` для заказов, профиля, темы и параметров; IndexedDB для загруженных файлов и макетов.
- Web Crypto для хеша пароля временного демоаккаунта.
- В оригинале нет `package.json`, сервера приложений, SQL-БД и npm-зависимостей. Node.js в этом экспорте нужен только как статический локальный HTTP-сервер из стандартной библиотеки.

## Что работает без инфраструктуры ChatGPT Sites

Страницы главной, входа и регистрации; кабинеты обеих ролей; светлая и тёмная темы; адаптивная вёрстка; анимации; настройки печати и расчёт цены; обработка PDF; конструктор, загрузка изображений и экспорт PNG; локальные заказы, статусы, переписка, учёт по группам и CSV. Эти части не обращаются к API Sites.

Не изменены существующие ограничения: сообщения и заказы локальные, нет удалённой доставки сотруднику, оплаты через банк, серверной защиты ролей, общей БД для разных устройств и прямого подключения принтера. Сотрудник может открыть PDF; физическая печать выполняется через доступный просмотрщик/браузер и установленный принтер. Часть встроенных демонстрационных заказов изначально не имеет исходного PDF.

## Оставшиеся внешние зависимости

1. **Google Fonts:** `dist/style.css` загружает Manrope с `fonts.googleapis.com` (файлы шрифта — с Google Fonts). Это зависимость от внешней сети, не от Sites. Импорт сохранён без изменений. При недоступности шрифта браузер использует Arial/sans-serif: функционал остаётся, точный вид текста может отличаться. Полностью автономных файлов Manrope в оригинале нет.
2. **Ранний прототип в Sites:** в `dist/app.js` сохранены ссылки на `https://printly-college-space.sergeevasofa950.chatgpt.site` из старых модальных окон загрузки/мерча. По этим ссылкам откроется другой, внешний сайт. Его страницы не являются файлами актуального проекта и не включены сюда как локальные страницы. Для локальных сценариев печати/мерча войди и используй разделы кабинета заказчика. Ссылки намеренно не заменены.
3. **Публикация Sites:** адрес `chatgpt.site`, права доступа и интерфейс платформы («Редактировать сайт», системное «Поделиться») принадлежат Sites/ChatGPT и не переносятся как код приложения. Для локального сайта они не нужны. `.openai/hosting.json` сохранён как исходная конфигурация привязки к Sites; наш локальный сервер её не использует и ничего не публикует.

## Данные браузера не входят в исходники

Заказы, сообщения, загруженные PDF, сохранённые макеты, настройки и профиль, которые уже находятся в браузере на адресе Sites, не переносятся автоматически в `127.0.0.1`. Хранилище привязано к адресу и порту. ZIP содержит исходники и встроенные демопримеры, а не копию пользовательского хранилища. Доступные макеты можно заранее сохранить штатным экспортом конструктора, отчёт — CSV; единого экспорта всех данных у оригинала нет.
